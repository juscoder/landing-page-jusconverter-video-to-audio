# JusConverter — Landing Page

Landing page moderna, minimalista y responsiva para **JusConverter**, una herramienta portable de Windows para convertir video a audio.

## Características de la Web
- **Diseño Minimalista:** Tema claro enfocado en la conversión y descarga rápida.
- **Hero Full-Screen:** Sección principal que ocupa toda la pantalla con diseño centrado.
- **Optimización SEO:** Meta tags configurados para buscadores y redes sociales (Open Graph & Twitter Cards).
- **Responsiva:** Totalmente adaptable a dispositivos móviles y tablets.
- **Organizada:** Estructura de archivos limpia con separación de HTML, CSS y JS.
- **Dinámica:** Año del footer actualizado automáticamente vía JavaScript.

## Tecnologías Utilizadas
- [Tailwind CSS](https://tailwindcss.com/)
- [Font Awesome](https://fontawesome.com/)
- [Inter Google Fonts](https://fonts.google.com/)
- JavaScript (Vanilla)

## Instalación y Uso
Simplemente abre el archivo `index.html` en tu navegador o despliega los archivos en cualquier servicio de hosting estático (GitHub Pages, Vercel, Netlify).
